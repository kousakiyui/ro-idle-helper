RO掛機小助手瀏覽器 V1.0｜Windows 使用教學

一、下載與啟動
1. 從 GitHub 發表頁下載 ROIdleBrowser_V1.0_Windows.zip。
2. 解壓縮到可寫入的資料夾，例如「下載」或「文件」下的新資料夾。
3. 雙擊 ROIdleManager.exe。需要已安裝 Google Chrome，以及 Windows 的 .NET Framework 4.8 或更新版本。免安裝 Node.js、.NET 8 或篡改猴。

二、開啟遊戲
• 點 A1、A2 或 A3 可單開該格。「一鍵全開 A 組」會開三格。
• 「選擇開啟格數」可選 A～E 組與 1～3 格。「設定首頁捷徑」可把常用的 B～E 組加到首頁。
• 每格有獨立的 Chrome 登入資料。遊戲格上方可按「首頁」或「重整」。需要修改起始網址時，使用「進階設定 → 遊戲與瀏覽器 → 編輯網址」。

三、使用助手腳本
• 內建助手預設使用正式版，可在「進階設定 → 腳本」開關或切換版本。切到測試版前會提醒可能出現功能失效或穩定性問題。
• 點首頁的「更新腳本並重整」可更新目前選用的助手，並重新整理已開啟的遊戲格。請先完成當下操作。
• 「自訂腳本管理」支援匯入本機 .user.js 或 HTTPS 下載網址。新增後預設停用，可先選已開啟的格子試跑，再指定套用範圍並啟用。切換設定後，重整該格並查看載入結果。部分第三方腳本的 API 或外部依賴可能不支援。

四、更新程式與保留資料
• 程式每次啟動會檢查 GitHub，也可以按首頁的「檢查程式更新」。確認安裝後，程式會關閉遊戲格並重新啟動。
• 6.x 使用者可能先看到「6.3.0」更新提示。這是升級用的內部版號，安裝後視窗會顯示「RO掛機小助手瀏覽器 V1.0」。
• 手動升級時，先關閉舊版及它開出的 Chrome，再用新 ZIP 內的 ROIdleManager.exe 覆蓋原執行檔。保留原本的 Data 資料夾。
• 設定、瀏覽器登入資料、腳本與紀錄都放在 Data。可從「進階設定 → 資料」開啟。分享給其他玩家時，請分享官方 ZIP，避免把自己的 Data 一起打包。
